## 🎯 Supervised Learning
### 🔹 Regression Algorithms
Used for predicting continuous values.
- **Linear Regression**
- **Polynomial Regression**
- **Ridge Regression**
- **Lasso Regression**
- **ElasticNet Regression**
- **Bayesian Linear Regression**
- **Support Vector Regression (SVR)**
- **Quantile Regression**
- **Poisson Regression**
- **Decision Tree Regression**
- **Random Forest Regression**
- **Gradient Boosting Regression (XGBoost, LightGBM, CatBoost)**
- **Huber Regression**
- **Theil-Sen Estimator**
- **Passive Aggressive Regressor**

### 🔹 Classification Algorithms
Used for predicting discrete categories.
- **Logistic Regression**
- **K-Nearest Neighbors (KNN)**
- **Decision Trees**
- **Random Forest**
- **Gradient Boosting (XGBoost, LightGBM, CatBoost, AdaBoost)**
- **Support Vector Machines (SVM)**
- **Naïve Bayes (Gaussian, Multinomial, Bernoulli)**
- **Perceptron (Single-layer Neural Network)**
- **Multilayer Perceptron (MLP)**
- **Linear Discriminant Analysis (LDA)**
- **Quadratic Discriminant Analysis (QDA)**
- **Extreme Learning Machines (ELM)**
- **Hellinger Distance Decision Tree (HDDT)**

## 🎯 Unsupervised Learning
### 🔹 Clustering Algorithms
Used for grouping similar data points.
- **K-Means Clustering**
- **Hierarchical Clustering**
- **DBSCAN (Density-Based Spatial Clustering)**
- **OPTICS Clustering**
- **Gaussian Mixture Models (GMM)**
- **Mean Shift Clustering**
- **Affinity Propagation**
- **Self-Organizing Maps (SOMs)**
- **Fuzzy C-Means Clustering**
- **Spectral Clustering**

### 🔹 Dimensionality Reduction
Used for feature selection and visualization.
- **Principal Component Analysis (PCA)**
- **t-SNE (t-Distributed Stochastic Neighbor Embedding)**
- **UMAP (Uniform Manifold Approximation and Projection)**
- **Autoencoders**
- **Independent Component Analysis (ICA)**
- **Factor Analysis**
- **Multidimensional Scaling (MDS)**

### 🔹 Anomaly Detection
Used for detecting outliers and fraud detection.
- **Isolation Forest**
- **One-Class SVM**
- **Local Outlier Factor (LOF)**
- **Elliptic Envelope**
- **Mahalanobis Distance-Based Anomaly Detection**
- **Autoencoder-Based Anomaly Detection**
